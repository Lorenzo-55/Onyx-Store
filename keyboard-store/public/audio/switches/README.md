# Switch studio audio

All seven WAV files are original, procedurally generated placeholder effects created for this project. They are **not recordings of mechanical switches** and must not be presented as authentic switch sound comparisons. Each file uses a separate timbre, noise envelope and transient pattern, rather than pitch-shifting a shared sample.

Format: mono, 44.1 kHz, signed 16-bit PCM, 300 ms. No third-party recordings or licenses are involved.

To install authentic recordings, replace each matching WAV file with a licensed, trimmed keypress recording, normalize perceived loudness across the library, and retain its source and license here. Update the placeholder labels in the simulator and audio hook only after every sample has been replaced and verified. Keep the configuration disclaimer even after replacing the samples.
